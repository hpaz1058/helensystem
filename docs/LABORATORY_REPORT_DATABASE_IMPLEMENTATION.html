Task 3 — Design and Create Your Main Table 20 Points

Table Specification:

  • Table Name: products
  • Primary Key: product_id (Auto-increment integer)
  • Columns: product_id (INT), product_name (VARCHAR 100), category (VARCHAR 50), price (DECIMAL 10,2), stock_quantity (INT), description (TEXT)
USE thread_co_db;

CREATE TABLE products (
    product_id INT AUTO_INCREMENT PRIMARY KEY,
    product_name VARCHAR(100) NOT NULL,
    category VARCHAR(50) NOT NULL,
    price DECIMAL(10, 2) NOT NULL,
    stock_quantity INT NOT NULL DEFAULT 0,
    description TEXT
);
